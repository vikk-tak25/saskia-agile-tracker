# Agile Tracker

Agile Tracker is a Kanban-style web application for managing user stories.

## Technologies

- Node.js
- Express
- Vite
- Vanilla JavaScript
- JSON file storage

## Run Locally

```bash
npm install
npm run dev
```

The frontend will run through Vite and the API will run through Express.
